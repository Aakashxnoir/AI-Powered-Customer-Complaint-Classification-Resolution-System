Questions

Read the documentation

Does ComplaintIQ send replies on its own?

No. Every draft waits for an agent to approve, edit or reject it.

Which complaints trained the classifier?

The Bitext customer support set plus synthetic complaints from 72 templates. Real complaints will score lower than the test set.

Can agents correct a complaint’s labels?

Yes. Category, sentiment, priority and department can each be corrected, and the corrections feed retraining.

Does ComplaintIQ need a GPU?

No. It runs on CPU. Loading about 1,200 demo complaints takes 3 to 5 minutes.

What if no Gemini key is set?

ComplaintIQ drafts the reply from a template built on the matched playbook.

Which languages can complaints be in?

English only, for now.

Complaint replies drafted from playbooks

ComplaintIQ finds the two approved playbooks closest to the complaint. Gemini writes the reply from those alone, and an agent approves, edits or rejects it.

  • 14 playbooks ship with the demo
  • Each draft cites the playbooks it used
  • Retraining is kept only if accuracy holds within 1 point
